# Sundrift

A quiet desert drive. No traffic, no clock — just an open road.

Web-based driving game built with Grok. Free-roam desert environment with keyboard + touch controls.

## Play

- **Desktop**: W / ↑ accelerate · S / ↓ brake & reverse · A / ← left · D / → right
- **Mobile**: On-screen gas / brake / steer buttons

## Stack

- Vite + React + TypeScript
- TanStack Router / Start
- Custom WebGL drive sim
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

## Deploy

Push to `main` → Vercel auto-deploys.

## Future

More features will be added over time as part of observing AI-assisted game development.
